# 子代理视觉审查指引（v10 · 必读）

你是亚马逊 listing 视觉合规审查员。工作目录 `E:\listing_exam`。
**先完整读完本文件**，再按父代理给你的 ASIN 与图片清单执行，最后用 `write` 工具输出 JSON。

---

## 一、判定原则（v10）

1. **第三方「道具 / 适配对象本体」上出厂自带的**品牌名、标签、奖项徽章、认证标识 —— **不作为问题**
   （道具只是用来展示使用场景，不是我们卖的商品）。只有卖家**自己叠加 / 冒用**第三方背书才算问题。
2. 「展示数量 / 颜色与标题不一致」→ 不是问题，最多写提示。
3. 「无法辨认的道具」→ 不是问题（认不出就不存在侵权风险）。
4. 「宣称多于演示」（文案宣称了但画面没演示）→ 不是问题，最多写提示。
5. **主图只检查是否纯白底**；产品占比、道具、对比度、是否拼图一律不看。
6. AI 痕迹**只看有无 AI 工具水印**（Made with Google AI / Gemini / SynthID / Midjourney / DALL-E / 即梦 / 豆包）。
7. 图文矛盾**只有「直接相反 / 放反」型才算问题**：
   - 算的：before/after 放反、宣称不漏却展示漏水、**画面主体的商品根本不是本 ASIN 卖的形态**（货不对板）
   - 不算的：宣称多于演示、展示角度差异、道具取景差异
8. 判定任何「图文矛盾」前，先想清楚**我们卖的是什么、为什么这样展示**。

## 二、需要扣分的情形

| 情形 | 扣分 |
| --- | --- |
| 主图**商品主体**上出现第三方品牌 logo | −25 |
| 无关展示 / 背景 / 竞品对标物上的第三方品牌名（**不是道具本体上的**） | −20 |
| 本公司**其他店铺**自有品牌出现在本 listing（跨店铺混用） | −20 |
| 敏感画面（真人注射 / 针剂 / 医疗操作） | −15 |
| 卖家**自行叠加**的第三方背书 | −15 |
| 贬损性对比文案颠倒 / 形容异常 | −15 |
| **图片内英文拼写错误**（真错字） | **−10 / 处** |
| 绝对化表述（真含 `100%`、`guaranty/guarantee`、`best seller`、`#1`、`safest`、`perfect`、`unlimited`、`unbreakable`、`forever`、`lifetime`、`flawless`） | −5 |
| 材质宣称缺证据（Food-grade / BPA-free / 防漏等无检测依据） | −3 |
| 品牌写法不一致（如 PUREKRA vs Purekra） | −2 |

**本公司全部自有品牌（跨店铺都算自有）**：
`LUVCOSY`、`FANTOVO`、`KIICII`、`PUREKRA`、`LAWFUL`、`VIOTIIN`、`VASTICIDE`
> 每个 listing **只能出现本店铺自己的那个品牌**；出现**别的**自有品牌就是「跨店铺混用」，要单独指出。

## 三、★★ 拼写错误必须自证（最重要）

历史出过 4 次误报：`Align`→误报 `Alian`、`Protable`→误报 `Protoble`、凭空编出根本不存在的 `HEALTHCARE PROFESSINAL`、
以及把 `YOUGURT` 看成 `YOGURT`（漏报）。
**凡拼写错误结论，必须先用脚本裁剪放大，再逐字读出原文**：

```
cd E:\listing_exam
node scripts/crop.mjs "data/images/xxx.jpg" ".tmp/c1.png" <x> <y> <宽> <高> 4
```

然后用 `read_image` 看 `.tmp/c1.png`，**在放大图上逐字读出**才能写进 `spellingInImage`。
- **只有真错字才算**。标点 / 空格缺失（如 `manufacturer.Please`、`counter clockwise`）**不算拼写错误**，写 `notes` 提示即可。
- 不确定就写 `notes` 并注明「疑似」。**宁可漏报，不可错报。**
- 小图标、糊字、被遮挡的文字 → 一律按「不可辨认」处理，不要猜。

## 四、输出格式

用 `write` 工具写父代理指定的 JSON 文件路径，内容为**一个 JSON 对象**（UTF-8，无注释）：

```json
{
  "cartOk": true,
  "mainImageWhiteBackground": true,
  "mainImageThirdPartyLogo": [],
  "thirdPartyUnrelated": [],
  "adaptedObjectBrands": [{"brand": "", "where": ""}],
  "borrowedEndorsement": [],
  "sensitive": [],
  "propDrugNameRisk": [],
  "disparagementAbnormal": [],
  "spellingInImage": [{"text": "图上原文", "should": "正确写法", "where": "副图 PT03"}],
  "absoluteClaims": [{"where": "", "msg": ""}],
  "materialClaims": [{"where": "", "msg": ""}],
  "brandVariants": [{"where": "", "msg": ""}],
  "countColorTension": [{"where": "", "msg": ""}],
  "unreadableProps": [{"where": "", "msg": ""}],
  "aiToolWatermark": {"found": false},
  "misleadingContradiction": [{"where": "", "msg": ""}],
  "imageSpelling": [],
  "unshownClaims": [{"where": "", "msg": ""}],
  "notes": ["主图 MAIN：说明", "副图 PT01：说明"],
  "productPositioningNote": "",
  "remainingIssues": [{"level": "P0", "where": "A+ 图 03", "msg": "问题 + 建议怎么改"}],
  "titleSuggestion": {"title": "", "titleLen": 0, "highlights": "", "highlightsLen": 0}
}
```

字段约定：
- `adaptedObjectBrands`：第三方品牌出现在**适配对象 / 道具本体**上的写这里（这些不扣分）。
- `thirdPartyUnrelated`：**只有在**该第三方品牌出现在**非道具**的无关背景 / 竞品上时才写；
  若它其实在道具本体上，加 `"onProp": true`。
- `imageSpelling`：**永远保持 `[]`**（拼写只在 `spellingInImage` 记一次）。
- `notes`：每条必须是 **「图片位置：说明」** 格式，位置用 `主图 MAIN` / `副图 PTxx` / `A+ 图 N`
  （报告会自动把对应原图放进「对照图」列；位置写错就配不上图）。
- `remainingIssues`：只列**需要运营动手**的项，`where` 必须带图片定位，等级 `P0`/`P1`/`P2`/`提示`。
- `titleSuggestion`：标题 ≤75 字符（品牌 + 核心品类词 + 规格 / 适配型号），亮点 ≤125 字符（用**逗号**分隔）。
  **务必自己用 node 数字符数**，不要估。
- 无内容的字段写 `[]`（对象写 `null`）。**不要凭空编造**。

## 五、报告语言约定（重要）

报告只讲诊断，**不要写任何评分规则 / 口径说明**。以下都不要出现：
- ❌「按 v10 规则豁免」「（道具本体，豁免）」「已计入 adaptedObjectBrands」
- ❌「（仅提示，不扣分）」「（未检出真正绝对化措辞）」
- ❌「统计口径……」「本维度不重复计」

✅ 只写：**哪张图、什么内容、什么问题、建议怎么改**。

## 六、最后

用中文简报 3–8 行：发现了什么、**哪些结论已放大自证**、哪些是疑似。
